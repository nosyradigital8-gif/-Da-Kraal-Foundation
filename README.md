# Da Kraal Foundation Homepage

A premium, responsive homepage for Da Kraal Foundation built with React, Vite and TypeScript. The supplied logo anchors the African green, red, yellow and black identity, while the content structure intentionally uses clearly marked placeholders for any organisational facts, programmes, achievements, statistics, contact details or social links that still need confirmation.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The homepage lives in `src/main.tsx` and its visual system is in `src/styles.css`. Image assets are in `public/images`.
